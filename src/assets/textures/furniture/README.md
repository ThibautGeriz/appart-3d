# Furniture textures

CC0 scans from [Poly Haven](https://polyhaven.com/textures), attached to the
furniture GLBs at export (`npm run export:glb`), by material name (see
`src/models/furniture/materials.ts`). Colour maps at 1K (JPEG q72), normal
(OpenGL) and roughness maps at 512 px. The material colour tints each scan to
the product photos.

| Scan                        | Used for                                  | Real-world size |
| --------------------------- | ----------------------------------------- | --------------- |
| `rosewood_veneer_02`        | Valmo: recycled teak top                  | 1 m             |
| `european_walnut_veneer_04` | Willow: teak slab                         | 1 m             |
| `ash_veneer`                | Raia: suar slab · Mackay: elm seat        | 1 m             |
| `brown_planks_08`           | Bistrot: recycled elm · Dustin: boat wood | 1 m             |
| `brown_planks_09`           | Westmount: fir                            | 1 m             |
| `fabric_leather_01`         | Norway chair: microfibre seat             | 0.4 m           |
| `oak_veneer_01`             | Norway chair and coffee table, Ontario    | 1.83 m          |

`fragranite_diff.jpg` is not a scan: a seamless speckle (quartz grains and dark
flecks) generated by `scripts/gen-fragranite.py` for the Franke Kubus sink
(Fragranite "gris ardoise"), tinted by the material colour.

`roma_mesh_diff.jpg` / `roma_mesh_nor.jpg` are not scans either: the Roma sofa's
3D mesh fabric (honeycomb of ~3 mm holes), grayscale so the toolbar's colour
tints it, generated by `scripts/gen-roma-mesh.py`.

`oak_veneer_01` reuses the colour map in `../oak_veneer_01.jpg`; only its
normal and roughness maps live here.
